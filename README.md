# Ipek_Yolu_Tuccar_Oyunu
OYUNUM GELİŞTİRİLMEYE DEVAM EDECEKTİR.
Marco polonun izinden ilerleyen ve bu yolculuğunda başta ipek yolu olmak üzere farklı coğrafyalara ve krallıklara giderek tüücarlık yapan bir gezginin hikayesi. Karakterinizi özelleştirebilir, yük taşımak kullanacağınız hayvanı belirleyebilir ve yolda karşılaşacağınız yoldaşlarınız ile ekstra güçlenebilirsiniz. İyi oyunlar dilerim.
